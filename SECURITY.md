# Security Policy

## Supported Version

This repository is currently maintained as a single active prototype branch.

## Reporting a Vulnerability

If you discover a security issue:

1. Do not post it publicly in a GitHub issue.
2. Share a private report with the project maintainer first.
3. Include reproduction steps, impact, and any suggested mitigation if possible.

## Notes

- This project is a research and demonstration prototype.
- It is not intended to manage live capital or production brokerage credentials without additional hardening.
