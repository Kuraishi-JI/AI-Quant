# Code of Conduct

This project is committed to a respectful, constructive, and inclusive community.

## Our Standards

Examples of behavior that contributes to a positive environment:

- showing empathy and patience
- giving actionable and respectful feedback
- assuming good intent while staying honest
- focusing discussion on the work, not the person

Examples of unacceptable behavior:

- harassment, intimidation, or discrimination
- insulting, demeaning, or inflammatory language
- bad-faith arguments or personal attacks
- sharing private information without permission

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, or other contributions that violate this code of conduct.

## Scope

This code of conduct applies within project spaces and in public interactions representing the project.
